About this overlay

Talking Pet TTS pairs a peeking Frills mascot with a customizable speech bubble that pops up whenever a gift or viewer message plays aloud. It cleans out links, enforces per-viewer cooldowns, and drops gracefully to free browser voices if Frills Plus is not on.

How to test on someone’s live stream locally

  1. Run the Frills helper locally (npm run tiktok) and open this page from the printed address.
  2. Pick your pet (Frog, Cat, Bunny, or Hamster) and click Gift thank-you or type a custom line above.
  3. Type any live streamer’s TikTok username in Step 3 to hear their live gifts and chat read out in real time.
  4. Copy your overlay link into OBS or TikTok LIVE Studio as a Browser source.
