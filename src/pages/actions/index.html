Quick setup guide

  1. OBS Studio: Click + under Sources → choose Browser → name it "Frills Commands" → paste your link → set width 1920 and height 1080 (or 1080 × 1920 for vertical).
  2. Streamlabs: Click + → choose Browser Source → paste your link → done.
  3. TikTok LIVE Studio: Click Add Source → choose Link / Webcast → paste your link → done.
