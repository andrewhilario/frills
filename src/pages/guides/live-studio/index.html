Add a chat overlay to TikTok LIVE Studio

TikTok LIVE Studio can show a web page on your stream, so a Frills chat overlay can go in it as a link source. We want to be honest: we have not been able to test every version of Studio ourselves, so this page says what we know, what other streamers report, and what to do when the overlay does not show.

Updated {{updatedHuman}}

The short version

  1. Get your link

    Open the editor, pick a look, type your TikTok @name and copy your link. Not LIVE yet? Type frills_demo to practice with made-up chat.

  2. Add it as a source in Studio

    In LIVE Studio, add a source and choose the link choice (some versions call it Browser or Web page). Paste your link.

  3. Make it as big as your scene

    Stretch the source across the whole scene, then place your chat inside it. The overlay is see-through, so a big source does not cover anything. For a vertical LIVE the scene is 1080 by 1920: see what size the overlay should be.

  4. Check it before you go LIVE

    The test guide shows how to see practice chat in Studio first, so you are not guessing when you are LIVE.

If the overlay shows tiny, or not at all

  • It looks like a dot in a corner. Some streamers report that Studio opens a link source at zero size. Stretch it by hand across the scene.
  • It will not stretch. Other streamers report a workaround: show the overlay in OBS, turn on OBS’s Virtual Camera, and add that camera as a source in Studio. We have not tested this ourselves.
  • It is blank. Real chat only shows while you are LIVE. Use frills_demo to check the source, then read chat not showing?, which goes through the causes in order.
  • It disappears during a battle. We have seen this reported for link sources, and we have not confirmed it. If it happens to you, please tell us.

What we know, and what we do not

  • We know: a Frills overlay is an ordinary web page, so anything that can show a web page can show it.
  • We have not confirmed: that every version of Studio opens a link source at the right size, and that sound alerts play in Studio (the alerts guide says the same).

Questions

Does TikTok LIVE Studio support browser sources?

Other streamers’ guides say Studio has an Add source button with a Link choice, which some versions call Browser or Web page. We have not confirmed it in every version.

Why does my overlay look tiny in LIVE Studio?

Some streamers report that Studio opens a link source with a size of zero. Stretch the source by hand across the scene. If it will not resize, try the OBS Virtual Camera workaround above.

Can I use OBS or Streamlabs instead?

Yes. The overlay works the same in any app that can show a web page. The setup guide shows each step in OBS.

I use LIVE Studio. How can I help?

Tell us what happened on the feedback page, and choose TikTok LIVE Studio as your app. It is the only way we learn what each version does.
