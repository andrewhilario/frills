Test your overlay without going LIVE

Real chat only shows up while you are LIVE, so an overlay you have just set up looks empty. To check it first, use the practice name frills_demo. Frills makes up chat for it, with moderators, gifts and the odd deleted message. Nothing is sent to TikTok.

Why you see nothing

The overlay is see-through and has no messages until someone chats in your LIVE. If you add your own @name before you are LIVE, the preview and your streaming app stay empty, and that looks like a mistake when it is not. The practice name gives you chat on demand.

Test it in the editor

  1. Open the editor

    Go to the editor and pick a look in step 1.

  2. Type the practice name

    In step 2, keep TikTok picked, type frills_demo and press Connect.

  3. Watch the preview

    Within a few seconds chat starts to appear in the preview at the top. A new message arrives every few seconds, so give it a moment. Change a colour or a look and watch the same messages change.

Test it in your streaming app

This checks the part the editor cannot: that your streaming app really shows the overlay, at the right size, with a see-through background.

  1. Copy the link with the practice name in it

    With frills_demo still typed in step 2, press Copy link in step 3. The link will look like this:

    {{siteAddress}}/overlay/?channel=frills_demo&platform=tiktok&look=bubblegum

    You can also take any Frills link you already have and change the part after channel= to frills_demo.

  2. Paste it into a source

    Add a Browser source (some apps call it a web page or link source) and paste the link. The setup guide has the steps for OBS. For a vertical LIVE use a size of 1080 wide by 1920 high.

  3. Look at the scene

    Made-up messages should appear over your game or camera within a few seconds. Check that the background is see-through, that the chat sits where you want it, and that the text is easy to read on your picture.

Before you go LIVE, put your own name back

Do not forget this. A link with frills_demo in it shows made-up chat, never your real chat. Open the editor, type your own @name in step 2, copy the link again and paste it into your source to replace the practice link. Then go LIVE and check that a real message shows up.

A second way: &demo=1

Add &demo=1 to the end of any Frills link and the source shows made-up messages made inside the page itself. It does not connect to anything, so it only tests how the overlay is drawn and shown. Use frills_demo when you also want to test the connection, the way real chat arrives.

If something looks wrong

  • Nothing shows up. Wait ten seconds. A small note appears in the bottom corner of the source while it connects, or if it cannot. Check that the name is exactly frills_demo, with an underscore and no @.
    • {{{testBusy}}}
  • The background is not see-through. In OBS, check that the Custom CSS box still has its default. In other apps, look for a transparent background option on the source.
  • The source is tiny or the wrong size. Set its width and height again, or stretch it by hand across the scene.
  • It works with &demo=1 but not with frills_demo. The overlay itself is fine, and the problem is the connection. Reload the source and try again in a minute.
