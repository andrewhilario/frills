Show TikTok and Twitch chat in one overlay

If you stream to TikTok and Twitch at the same time, you do not need two chat overlays. Frills can read both accounts into the same speech bubbles, with a small icon on each message so you can tell where it came from. It is free, it is one link, and there is no account to make. This part of Frills is in beta.

How to set it up

  1. Open the chat editor and pick a look.
  2. Under the account, choose Both. Type your TikTok @name and your Twitch channel.
  3. Press the test message button. In practice chat the made-up messages take turns being TikTok’s and Twitch’s, so you can see the icons.
  4. Copy your link and add it to your streaming app as one Browser source (some apps call it a web page or link source). The setup guide has every step.

Prefer questions? The Quick start has a "Both at once" choice and makes the links for you.

What you get

  • One chat, one source. TikTok and Twitch messages arrive in the same list, in the order they came.
  • A small platform icon on every message. You can switch it off under Platform icon.
  • Each platform on its own. A message that a Twitch moderator deletes, or a timeout, only touches that person’s Twitch messages, never someone with the same name on TikTok.
  • If one is not ready, the other keeps working. A short line says which side is waiting, for example that your TikTok is not LIVE yet, and the other chat carries on.

Good to know

  • TikTok chat comes through the free Frills relay, which is a beta with a limited number of spots, so it can make you wait when it is busy. Twitch is read straight from your browser.
  • Gifts (and the gifter dot) only exist on TikTok, so they only ever show for TikTok. A rose is a TikTok gift.
  • The alerts overlay, last gifts, goals and top likers are separate overlays with their own links. Alerts work for both platforms; the others are TikTok only for now. See more overlays.
  • Nothing shows? Go through the fixes for a chat that is not showing.
