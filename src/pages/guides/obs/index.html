Add Frills to OBS

Your chat goes into OBS as a Browser source: one link, pasted once. This takes a couple of minutes, and you only do it once.

  1. Make your link

    Open the editor, pick a look, type your TikTok @name or your Twitch channel in step 2, and copy the link from step 3. It already has your look and your account in it. {{{obsTikTok}}}

  2. Add a Browser source

    In OBS, find the Sources box, press + and choose Browser. Name it something you will recognise, like “Frills chat”, and press OK.

  3. Paste your link

    Paste it into the URL box. Leave “Local file” unticked.

  4. Set the size

    Set Width and Height to the space you want for chat. 500 by 800 is a good start for a column at the side. You can change it later by dragging the red handles on the source.

  5. Leave the rest alone

    Keep the custom CSS that OBS fills in: it is what makes the page see-through. Two boxes are worth knowing about. Refresh browser when scene becomes active reconnects chat each time you switch to that scene. Shutdown source when not visible stops the overlay while its scene is off screen, which saves resources.

  6. Place it

    New messages appear at the bottom edge of the source and push older ones up. Put the source where you want the newest message to sit.

If something looks wrong

  • Nothing shows up. A small note appears in the bottom corner of the source while it connects, or if it can’t. Check your name for typos. Messages only appear when someone chats. {{obsNothing}}
  • The background isn’t see-through. Check that the Custom CSS box still has OBS’s default, which starts with body { background-color: rgba(0, 0, 0, 0).
  • You want to test without chat. Add &demo=1 to the end of your link and the source shows made-up messages instead.
