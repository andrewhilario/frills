    How it works · Or set it up with the Quick start

About the beta ones. Alerts, last gifts and goals read follows, gifts and likes from TikTok through the free Frills relay. If connecting says the relay needs an update, please check back soon. The test buttons in each editor always work, so you can design yours first. Top likers counts the likes it sees from the moment it connects. TikTok and Twitch chat together is new: it has been tried with practice chats and a couple of real streams, but not on a long LIVE yet, so tell us how it goes.
